25 stars | Updated Aug 2025

This is a **Chinese-language** repo from someone who interviewed at major Chinese tech companies in 2025. What I verified it covers (from the table of contents):

- **Transformer + Attention** (MHA/MQA/GQA/MLA — including MLA which almost no other repo covers), positional encoding variants

- **RAG** fundamentals, chunking, retrieval, re-ranking, RAG evaluation
- **Agentic AI**: Function Call, MCP, Tool Use, ReAct, context engineering
- **Training optimization**: LoRA, PEFT, mixed precision, data/model/hybrid parallelism, memory estimation
- **Model compression**: pruning, knowledge distillation, quantization, MoE, parameter sharing
- **Practical problems**: catastrophic forgetting, vanishing gradients, long-context handling, hallucination
- **Framework comparison**: pretraining/fine-tuning/post-training frameworks, RL frameworks, Agent frameworks
- **DeepSeek R1/V3** specific questions — very current

**Honest caveat:** It's in Chinese. But the topics listed are translatable, and if you can use browser translate or read Chinese, it's actually one of the most comprehensive single repos for breadth. Answers were partially generated by Gemini/GPT-4o per the author's disclosure.
